Privacy Policy

rclone-Ebook2025 is a personal application used only by the application owner to synchronize files between the owner's Windows computer and Google Drive.

Google Drive Data

The application accesses the owner's Google Drive data only for file synchronization, including uploading, updating, renaming, moving, and managing files in the owner's Google Drive account.

Data Sharing

Google user data accessed by this application is not sold, shared, or transferred to third parties.

Data Storage

The application does not operate a separate server or database for storing Google user data. Authentication credentials are stored locally on the owner's computer by rclone.

Purpose

Google user data is used solely for synchronization between the owner's computer and the owner's Google Drive account.
